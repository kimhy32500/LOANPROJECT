# 신용대출 조회 자동화 테스트 프로젝트 (Appium)

Appium과 Pytest를 활용하여 하이브리드 앱 환경의 대출 조회 시나리오를 자동화 테스트한 프로젝트입니다.

테스트 자동화를 처음 학습하며 진행한 프로젝트로,
모바일 앱 환경에서의 자동화 흐름과 반복 테스트 효율화를 직접 경험해보기 위해 진행했습니다.

특히 Appium 기반 자동화를 구현하면서 발생했던 플레이키 테스트와 타이밍 이슈를 직접 해결해보며,
자동화 테스트의 안정성이 얼마나 중요한지 체감할 수 있었습니다.

## 1. 프로젝트를 진행한 이유

이전 회사에서 모바일 앱 테스트 업무를 수행하면서
“테스트 자동화에 Appium을 사용한다”는 이야기를 처음 접했습니다.

실제 자동화 환경은 보안상 직접 확인할 수 없었지만,
퇴사 후 테스트 자동화 기술이 점점 많이 도입되고 있다는 점을 느끼면서 직접 학습이 필요하다고 판단했습니다.

당시 들었던 Appium 기반 자동화 방식을 직접 구현해보자는 생각으로 프로젝트를 시작하게 되었습니다.

## 2. 테스트 대상 앱

로그인부터 대출 심사 결과 확인까지의 흐름을 가진 간단한 금융 서비스를 직접 제작하고 테스트 대상으로 사용했습니다.

직업 유형에 따라 입력 필드와 심사 흐름이 달라지도록 구성했으며,
반복적으로 수행되는 주요 시나리오를 자동화하는 데 목적을 두었습니다.

### 테스트 대상 주요 기능
- **직업 유형 4종**: 직장인/공무원, 개인사업자, 프리랜서, 무직
- **연소득 기준 심사**: 3,000만원 이상 승인 / 미만 거절
- **유효성 검사**: 직장명·사업장명 2글자 이상, 연소득 1글자 이상 입력 시 신청 활성화
- **팝업 처리**: 로그인 실패, 로그아웃 확인, 신청 완료 팝업

├── requirements.txt
└── README.md

## 6. 자동화하면서 경험한 점

### 플레이키(Flaky) 테스트 경험
자동화를 진행하면서 가장 어려웠던 부분은 불규칙적으로 성공과 실패가 반복되는 플레이키 테스트 현상이었습니다.
같은 테스트인데도 실행할 때마다 결과가 달라졌고, 어느 시점에서 문제가 발생하는지 정확히 파악하기 어려웠습니다.
원인을 찾기 위해 각 단계별 실행 로그를 출력하도록 수정했고, 어느 구간에서 불안정하게 동작하는지 확인하면서 테스트 흐름을 추적했습니다.
이후 문제 구간에 대기 로직을 추가하여 테스트가 안정적으로 동작할 수 있도록 수정했습니다.
이 과정을 통해 자동화 테스트에서는 “동작하는 것”만큼이나 “안정적으로 반복 실행되는 것”이 중요하다는 점을 크게 느낄 수 있었습니다.

### 하이브리드 앱 자동화 경험
네이티브 앱 영역과 WebView 영역을 오가며 테스트를 진행했습니다.
처음에는 컨텍스트 전환 개념이 익숙하지 않아 어려움을 느꼈지만, 실제 모바일 앱 자동화 환경에서는 웹과 네이티브 영역이 함께 사용될 수 있다는 점을 경험할 수 있었습니다.
XPath, CSS Selector 등 다양한 방식으로 요소를 탐색해보며 모바일 환경에서의 자동화 흐름을 학습할 수 있었습니다.

### 반복 테스트 자동화 경험
수동으로 반복 수행해야 하는 시나리오를 자동화하면서 테스트 시간이 크게 줄어드는 것을 체감할 수 있었습니다.
특히 자동화를 통해 절약된 시간을 추가 검증이나 다른 품질 확인 작업에 사용할 수 있다는 점에서, QA 업무에서 자동화가 왜 중요한지 직접 이해할 수 있었습니다.

### 이후 Playwright를 학습하게 된 계기
Appium 프로젝트 이후, 실제 자동화 업무를 수행 중인 지인들과 이야기를 나누면서 최근에는 Playwright 기반 자동화를 사용하는 기업들이 많다는 점을 알게 되었습니다.
기존 Appium 환경에서는 타이밍 이슈와 플레이키 현상을 자주 경험했기 때문에, 보다 안정적인 웹 자동화 환경도 학습해보고 싶다는 생각이 들었습니다.

이후 Playwright를 학습하면서 Auto-Wait 기능으로 인해 별도의 wait 처리를 많이 추가하지 않아도 테스트가 안정적으로 동작하는 것을 체감할 수 있었고,
왜 많은 기업들이 Playwright를 활용하는지도 이해할 수 있었습니다.

## 7. 설치 및 실행

```bash
# 저장소 클론
git clone https://github.com/kimhy32500/LOANPROJECT.git
cd LOANPROJECT

# 라이브러리 설치
pip install -r requirements.txt
```

### pytest 기반 실행 (권장)

```bash
# 기본 실행
pytest test_loan_regression.py -v

# HTML 리포트 생성
pytest test_loan_regression.py -v --html=report/report.html --self-contained-html
```

### 순차 실행 (레거시)

```bash
python regression_main.py
```

> ⚠️ **실행 전 주의사항**
> 1. **Appium Server**가 실행 중이어야 합니다. (기본 포트: 4723)
> 2. **Android Emulator**가 구동된 상태여야 합니다.
> 3. 에뮬레이터 내의 **Chrome 브라우저 버전**과 `webdriver-manager`가 관리하는 버전이 일치해야 합니다.
